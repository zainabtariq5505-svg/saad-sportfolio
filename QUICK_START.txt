❌ Page not loading?
   → Check if server is still running
   → Try: http://127.0.0.1:8000/ instead

❌ Changes not showing?
   → Hard refresh: Ctrl + Shift + R
   → Clear browser cache

❌ Console errors?
   → Press F12 → Check Console tab
   → Supabase warnings are normal locally

❌ Supabase features not working?
   → Normal! Works when deployed online
   → Visitor tracking needs live URL

❌ Port 8000 already in use?
   → Try different port: py -m http.server 3000
   → Access at: http://localhost:3000/
